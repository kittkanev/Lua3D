# Roblox DOORS Clone / Клон DOORS в Roblox Studio

Проект представляет собой полноценную, готовую к запуску и расширению реализацию хоррор-игры в стиле **DOORS** для Roblox Studio, написанную на **Luau** и собранную с помощью **Rojo**.

---

## 🌟 Основные возможности / Features

1. **Процедурная генерация комнат (Procedural Room Generation):**
   - Динамическое создание до 100 уникальных комнат со стенами, потолками, полом, освещением, мебелью и шкафами.
   - Автоматический спавн и удаление прошлых комнат для оптимизации производительности.

2. **Двери и ключи (Doors & Locks):**
   - Двери с указанием номера комнаты (Door 1, Door 2...).
   - Случайные запертые двери, требующие нахождения ключа в предыдущих комнатах или тумбочках.
   - Анимированное открытие дверей с проигрыванием звуков.

3. **Система пряток в шкафах (Closet Hiding System):**
   - Прятки в шкафах с помощью `ProximityPrompt`.
   - Автоматическое скрытие персонажа (прозрачность моделей) и отключение коллизий при прятках.
   - Защита от кемпинга (**Hide**): при слишком долгой жизни в шкафу экран начнет дрожать, появится красная виньетка, а затем монстр Hide выбросит игрока и нанесет урон.

4. **Предметы и инвентарь (Items & Loot):**
   - Поиск лута в тумбочках (Drawers) по таблице шансов drop'а.
   - **Фонарик (Flashlight):** Освещает путь, с расходом батареи.
   - **Зажигалка (Lighter):** Альтернативный источник света с расходом топлива.
   - **Витамины (Vitamins):** Временный буст к скорости бега персонажа.
   - **Батарейки (Batteries):** Пополнение заряда фонарика.
   - **Ключи (Keys):** Для отпирания запертых дверей.

5. **Монстры и Сущности (Entities):**
   - **Rush:** Мигание света во всех ближайших комнатах $\rightarrow$ пролет монстра сквозь двери со звуковым сопровождением $\rightarrow$ уничтожение игроков, не успевших спрятаться в шкаф, и разбивание ламп.
   - **Screech:** Появляется в темных комнатах, издает характерный звук («Psst!») $\rightarrow$ если игрок не успевает повернуть камеру в его сторону, наносит урон.
   - **Hide:** Выгоняет игрока из шкафа при долгой сидении.

6. **Атмосфера, Графика и Камера:**
   - Полноценная настройка мрачной атмосферы, тумана, ColorCorrection и Bloom.
   - Тряска камеры при приближении Rush или предупреждениях Hide.
   - Кастомные скриптовые скримеры (Jumpscares) и уведомления на UI.

## 🚀 Как запустить проект в Roblox Studio

### Способ 1: Использование готового `.rbxl` файла (Самый простой)
1. Откройте **Roblox Studio**.
2. Нажмите `File` $\rightarrow$ `Open from File...`.
3. Выберите файл **`RobloxDoorsClone.rbxl`** из этой папки.
4. Нажмите **Play (F5)** для тестирования игры!

### Способ 2: Использование Rojo (Для разработки)
1. Установите [Rojo](https://rojo.space/).
2. В терминале в корневой папке проекта запустите плагин Rojo:
   ```bash
   rojo serve
   ```
3. В **Roblox Studio** откройте пустой Baseplate, запустите Rojo Plugin и нажмите **Connect**.
4. Все изменения в Luau скриптах будут синхронизироваться в реальном времени!

## ⚙️ Настройка параметров игры

Все ключевые параметры игры настраиваются в файле `src/ReplicatedStorage/Modules/GameConfig.luau`:
- **Скорость и урон монстров** (Rush, Screech, Hide)
- **Шансы запертых дверей и лута в тумбочках**
- **Размеры и лимит комнат (до 100 комнат)**
- **Характеристики предметов (емкость батарей, скорость витаминов и т.д.)**
