LUNORYX 0.1.0-alpha.1 — РАННЯЯ ТЕСТОВАЯ ВЕРСИЯ

Возможны баги, нестабильная работа и потеря несохранённых изменений.
Это первый ознакомительный выпуск, а не стабильная production-версия.
Сохраняйте резервные копии важных файлов.

ЗАПУСК
1. Распакуйте весь архив в отдельную папку.
2. Запустите Lunoryx.exe. SDL2.dll должна оставаться рядом с ним.
3. Требуются Windows x64 и драйвер с поддержкой OpenGL 2.1 compatibility.
4. Пример examples/orbit.lua можно вставить в Script Editor и нажать Run Script.

Lua-скрипты считаются доверенными: они имеют доступ к файлам и процессам.
Экспорт GLB сохраняет геометрию и материалы, но не проект редактора и не Lua-код.

Сообщить о баге: https://github.com/kittkanev/Lua3D/issues
Укажите версию, Windows, GPU/драйвер и шаги воспроизведения.

EARLY TEST RELEASE: bugs, instability and loss of unsaved work are possible.
Extract the entire archive and keep SDL2.dll next to Lunoryx.exe.
