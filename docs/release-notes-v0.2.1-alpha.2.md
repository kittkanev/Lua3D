# Lunoryx Studio 0.2.1-alpha.2 — возвращение к v0.2

Восстановлен прежний редактор v0.2: Dear ImGui, докинг, Explorer, Properties,
Tools, вкладки кода, старые Lua API и формат проектов schema 1.
Нативная переработка v0.3 отменена. Это дополнение существующего редактора.

Добавлено и исправлено:

- Move/Rotate/Scale в прежней вкладке Scene: осевые и плоскостные манипуляторы
  ImGuizmo, local/world, snapping и мультивыбор. Q/W/E/R переключают режим.
- Демонстрационная Lua-анимация при запуске приостановлена, чтобы она не
  перезаписывала ручные трансформации. Её можно включить прежней кнопкой Play Lua.
- Undo/Redo объектов и геометрии: Edit или Ctrl+Z/Ctrl+Y в viewport.
- Многоуровневая сетка следует за камерой и продолжается за пределы старых 20×20.
  Увеличен диапазон камеры; шаг сетки, FOV, чувствительность и clipping настраиваются.
- Settings: параметры камеры, сетки, привязки, темы, VSync и звука сохраняются
  в пользовательском каталоге Studio-v02, отдельно от настроек отвергнутой v0.3.
- Audio: WAV/WAVE/W64/RF64, MP3, FLAC, OGG/OGA (Vorbis). Импорт по пути или drag/drop,
  preview/stop, volume/pitch/loop/autoplay и 3D-позиция. Звуки сохраняются в проекте;
  старые проекты без звуков открываются без конвертации.
- MCP stdio (`Lunoryx.exe --mcp`) управляет тем же старым движком: объекты,
  трансформации, проекты, GLB, Lua, звуковые ссылки, undo/redo.

Один EXE, без консоли и дополнительных SDL/Lua/audio DLL.

Это ранняя тестовая версия. Ограничения v0.2, не относящиеся к этим исправлениям,
сохранены: AABB-физика, Join без булевой CSG, персонаж без skeletal rig,
процедурное окружение. AAC/Opus/AIFF/AU в этом исправлении не поддерживаются.
Новые панели GUI/дебаггера и прочие большие системы из v0.3 сюда не переносились.

Проверены прежние тесты, новые roundtrip/undo тесты, фактический drag через
ImGui/ImGuizmo, мультивыбор, сохранение звуков, MCP и декодирование/микширование аудио.

Дополнительно сохраняются Move snap, Local и включение snapping между запусками.
Windows CI также проверяет реальное декодирование/микширование WAV без аудиоустройства.
