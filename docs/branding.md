# Lunoryx Studio logo

Generated with the built-in imagegen tool. The transparent mark combines a lunar arc,
a stylized lynx silhouette and an isometric cube in cyan and periwinkle.

Project assets:
- `assets/lunoryx-logo.png`: 512 px PNG for the README and brand references.
- `assets/lunoryx.ico`: Windows executable icon, multiple sizes.
- `assets/logo_data.h`: PNG embedded in the executable for the application icon and API Docs.

Generation prompt:

> Use case: logo-brand. Asset type: application icon and logo mark for Lunoryx, a creative 3D scene editor with Lua scripting. Create one bold distinctive geometric emblem: an angular crescent embracing an isometric faceted cube, suggesting a luminous lunar lynx silhouette through negative space, abstract and elegant. Cyan and cool periwinkle on the mark, clean flat vector-like edges, high contrast, restrained subtle gradient, no glow haze. Centered square composition, generous clear padding, readable at 32 px. Transparent background. Mark only, no text, no letters, no mockup, no watermark.
