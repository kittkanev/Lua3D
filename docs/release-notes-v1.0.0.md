# Lunoryx Studio 1.0.0 — первый стабильный выпуск

Создание сцены, моделирование, UV и материалы, Lua, симуляция и сборка самостоятельной игры доступны в прежнем интерфейсе Studio. Сохранены тема, докинг, Explorer, Properties, Tools и вкладки кода.

## Скачать

- **Lunoryx.exe** — самостоятельный Windows x64 редактор без отдельной SDL/Lua/audio DLL и консоли.
- **Lunoryx-v1.0.0-windows-x64.zip** — редактор, примеры, инструкции и лицензии.
- **GemTrail.exe** — проверенная игра в одном файле: WASD, Space, R для перезапуска, Escape для выхода.
- **SHA256SUMS.txt**, **REPORT.md** и PNG — контрольные суммы и визуальный отчёт из проверенной сборки.

Требуются Windows x64 и OpenGL 2.1 compatibility с framebuffer objects.

## Возможности v1

- Примитивы, мультивыбор, Move/Rotate/Scale, local/world, snapping и сохраняемые настройки.
- Полигональное редактирование вершин, рёбер и граней; Extrude, удаление, Merge by Distance, нормали, Join и скульптинг.
- Стек Mirror, Array, Loop Subdivision и Bevel; настоящие Union/Difference/Intersection через Manifold.
- xatlas-развёртка и упаковка, явные швы, острова UV, перемещение/вращение/масштаб, материалы по граням и PNG/JPEG-текстуры.
- Статический импорт GLB с трансформациями, нормалями, UV, цветами и материалами; автономный экспорт с текстурами.
- Lua 5.4, игровой ввод, камера от третьего лица, счёт, HUD, звук и перезапуск. Play создаёт новое Lua-состояние, Stop восстанавливает редактор.
- Native Build Game.exe упаковывает проект и импортированные ресурсы. Сборка работает без исходных файлов, редактора и компилятора.
- Schema 2 с чтением schema 1, атомарное сохранение, Save As, защита несохранённых изменений и история операций сцены, звука и окружения.
- MCP stdio с прежними Lua API и стабильными ID объектов.

## Проверки и отчёт

Все файлы этого выпуска собраны из коммита, указанного GitHub у релиза, и прошли его CI:

- Linux и MinGW с -Werror; нативное выполнение на Windows.
- ASan, UBSan и LeakSanitizer; Lua-ошибки, ограничение инструкций и восстановление стека.
- Объёмы CSG, замкнутый Bevel, модификаторы, сохранение материалов, Weld/удаление и повторная UV-развёртка со швами.
- Совместимость проектов, Undo/Redo, восстановление после Play, защита от устаревшего результата фоновой операции.
- Независимый Khronos Validator для обычного и текстурного GLB: без ошибок и предупреждений.
- WAV, W64, RF64, MP3, FLAC и OGG из файлов и памяти; MCP.
- Упаковка в папке с кириллицей и пробелами; удаление исходного проекта, PNG и WAV; отклонение повреждённого контейнера и неверных диапазонов ресурсов.
- Linux/Mesa и Windows/Mesa: детерминированный ввод через настоящий контроллер, столкновения, сбор трёх предметов, ненулевой звуковой микс, HUD и чистый перезапуск.

`modeling.png`, `uv.png`, `gizmo-smoke.png` показывают работающий редактор; `game-linux.png` и `game-windows.png` — завершённый игровой сценарий. Mesa используется только для CI и не включается в приложение.

## Первый запуск

Tools → Character → Game / Build → New third-person example → Play Simulation. После проверки сохраните `.lunoryx` и нажмите Build standalone Game.exe.

## Границы v1

Физика AABB, простой освещённый viewport и статический GLB. Риг, скелетная анимация, нодовые системы, офлайн-рендер и полная совместимость с Blender остаются дальнейшим развитием.

Bevel требует замкнутой ориентированной топологии; новые поверхности получают слот материала 0. Булев результат требует новой UV-развёртки и настройки материала. Mirror копирует весь меш относительно локального начала. Импорт сообщает о пропущенных анимациях, морфах и нетреугольных примитивах; обязательные неподдерживаемые расширения и sparse-accessors отклоняются.

Лимиты: документ 32 MiB, упакованные ресурсы 512 MiB, текстуры 4096×4096, 200 000 вершин на меш и 1 000 000 на проект. В редактируемом проекте внешние ресурсы нужно переносить вместе с `.lunoryx`; игровой EXE содержит импортированные ресурсы внутри. Произвольные обращения Lua к файлам и процессам не виртуализируются. Скрипты остаются доверенными. Windows/Mesa не заменяет проверку всех пользовательских GPU.
